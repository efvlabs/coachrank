An old course idea, a half-built landing page, a possible partnership and a neglected writing series can all remain “active” without receiving real attention. Each still appears whenever you ask what to do next.

The cost is not only unfinished work. The list can conceal a decision you have postponed: which commitments still deserve a place in the current week?

[Getting Things Done's review materials](https://gettingthingsdone.com/2017/05/refresh-and-reset-with-the-weekly-review/) emphasize returning to a current view of your work. This project audit is a practical extension of that habit: examine the projects themselves, rather than repeatedly rearranging their tasks.

## Make the inventory concrete

List projects that imply a result requiring more than one action. Include the quiet ones you still feel responsible for, not just the projects visible in your main task tool.

For each, write the result in ordinary language. “Newsletter” is a channel. “Publish the first four issues for independent coaches” describes a bounded project. If the result has changed, record the current version.

Separate a commitment from an idea. An interesting possibility does not need to occupy the same space as work you have promised to deliver. Keeping an idea available is different from authorizing it to compete for today's attention.

## Ask what is actually keeping it open

A project may be waiting for information, missing a next action, lacking capacity or no longer worth doing. Those are different conditions.

Use a small inventory:

| Project question | What to record |
| --- | --- |
| What result are we pursuing? | A visible completion condition. |
| What happens next? | A specific action someone can begin. |
| What is blocking it? | A dependency, decision or resource. |
| Who relies on it? | People and promises affected by a change. |
| What does delay cost? | A concrete consequence, or an honest unknown. |

If you cannot explain why a project remains active, that is a reason to examine it. It is not automatically a reason to delete it. There may be a real obligation hidden beneath an unclear label.

## Make one of four decisions

Continue when the result matters, the next action is clear and capacity exists. Narrow when a smaller result can serve the current need. Pause when a real condition must change before work is worthwhile. Close when the project no longer justifies the remaining commitment.

Imagine a fictional founder with a broad course outline and a clear need to learn whether the audience understands the topic. Narrowing the project to one useful workshop may answer the present question. It should be described honestly as a smaller offer, not sold under the original course promise.

For a paused project, record the trigger for revisiting it. “Later” is hard to review. “After the current delivery cycle, when we know next month's available capacity” is more useful.

## Respect commitments when changing direction

If a client, colleague or collaborator depends on the project, communicate before treating it as paused or closed. Explain the change, its effect and the options available.

Do not erase a shared obligation merely because it no longer fits a personal productivity system. Some work needs renegotiation, a handover or a responsible finish. Make that process part of the decision.

Also preserve useful materials. A closed project may contain research, a reusable draft or a lesson about an assumption. Archive those with a short note so future you does not restart the same investigation without knowing it already happened.

## Give the remaining projects real space

Look at the coming week and identify where each active project can receive attention. Include preparation, coordination and review, not only the attractive creative task.

If the plan does not fit, return to the decisions. Adding more labels or a new task application will not create capacity by itself. You may need to narrow another result or communicate another change.

End the audit with a short active list and a separate place for ideas and paused work. Review it regularly enough that old projects do not quietly regain active status through guilt alone.

Ambition does not require every possible project to remain open. A deliberate portfolio of commitments gives worthwhile work a better chance of being completed, and gives you a clearer explanation for what you choose to do next.
