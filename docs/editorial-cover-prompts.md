# CoachRank Edition 02: cover-art prompts

All 25 articles ship with original graphic covers. These optional prompts can create photographic alternatives. Keep the current graphics until each alternative has been reviewed. Use 3:2 landscape framing, no text, no logos and no recognizable public figures. Label generated imagery as illustration; do not imply a documentary photograph.

## 01. Write it down before you know how it ends.

Article: /blog/decision-journal-before-the-outcome

Prompt: Art-directed editorial still life for an independent magazine about ambition and craft. Two branching cobalt paths with a single orange decision point on warm paper. Reimagine the composition as a physically built miniature set with matte cobalt-blue architectural forms and one luminous burnt-orange focal object. Deep midnight-blue seamless background with controlled directional rim lighting. Tactile plaster, paper and polished resin; precise geometry; generous negative space; a confident asymmetrical crop. The visual metaphor must remain legible at thumbnail size. Museum-quality object photography, subtle material detail, restrained palette, no text, no lettering, no watermarks, no people, no stock-business imagery. Landscape 3:2, 1536 by 1024 pixels.
